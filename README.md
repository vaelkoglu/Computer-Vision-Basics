# OpenCV & Python Fundamentals 🚀

A comprehensive collection of hands-on scripts and exercises exploring the core fundamentals of **Computer Vision** using Python and OpenCV. This repository serves as a practical workspace for mastering image processing techniques and matrix manipulations.

 Topics Covered
- **Image I/O & Window Management:** Loading, displaying, and managing windows (`cv2.imread`, `cv2.imshow`, `cv2.namedWindow`).
- **Color Spaces & Pseudo-Color Enhancement:** Converting color formats (`cv2.cvtColor`) and applying color maps (`cv2.applyColorMap` like `COLORMAP_JET`).
- **NumPy Integration:** Understanding image matrices, properties (`shape`, `dtype`), and region-of-interest (ROI) slicing.
- **Pixel Arithmetic Operations:** Performing pixel-level additions and subtractions (`cv2.add`, `cv2.subtract`, and image resizing).

## 🛠️ Tech Stack & Tools
- **Language:** Python 3.x
- **Libraries:** OpenCV (`cv2`), NumPy
- **Environment:** PyCharm IDE / Virtual Environment (`venv`)

## 📂 Project Structure
- `Basic_Operations/` — Foundational scripts covering image loading, properties, and matrix manipulation.
- `Arithmetic_Operations/` — Pixel-level addition, subtraction, and handling dimension constraints.
- `Pseudo_Color/` — Heatmap generation and colormap enhancement scripts.
